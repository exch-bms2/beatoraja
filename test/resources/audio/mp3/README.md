# Synthetic MP3 Regression Fixtures

These files contain no external recordings or music. They were generated by
`bms.player.beatoraja.audio.Mp3TestAssets` using JavaCV 1.5.14 / FFmpeg
8.1.2-1.5.14 (the MP3 encoder selected by `AV_CODEC_ID_MP3`). Each input is
0.2 seconds of PCM16: amplitude 4000, left/mono 440 Hz and right 880 Hz.
There is no Xing header; all three have an ID3v2 header.

- `tone-44100-1.mp3`: mono, MPEG1, 128 kbit/s CBR.
- `tone-48000-2.mp3`: stereo, MPEG1, VBR quality 4.
- `tone-22050-2.mp3`: stereo, MPEG2, 64 kbit/s CBR.

`Mp3CompatibilityTest` pins the untrimmed decoded PCM byte counts and SHA-256
digests captured with **JLayer 1.0.1-gdx**, before changing the dependency.
MP3 encoder delay/padding is deliberately retained, matching the existing
decoder behavior rather than asserting that decoded duration is 0.2 seconds.
The application's trailing-zero-frame removal is checked separately.

The optional generator accepts a new output directory, requires FFmpeg natives,
and refuses to overwrite existing files. Normal regressions decode these checked-in
fixtures without loading FFmpeg or opening an audio device. Fixtures are test
resources only and must not enter the application JAR, Fat JAR or distribution ZIP.
